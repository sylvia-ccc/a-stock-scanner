## ✨ 功能

### 1. 个股全景扫描（网页版 + 命令行版）

输入任意 A 股代码（支持约 5400 只沪深标的），自动生成完整报告：

- **100 分制评分卡**：盈利能力 20 + 成长性 20 + 财务健康 15 + 估值 15 + 技术位置 15 + 股东回报 10 − 风险扣分
- **建仓决策卡**：明确的买卖动作与逐档触发价位（首批建仓价 / 加仓两档 / 止损价 / 减仓评估区），盘中取实时价、收盘后取收盘价
- **扣非核验**：归母净利 vs 扣非净利对比，识别「政府补贴/卖资产撑利润」的假增长
- **周期分位提示**：年度扣非在近 10 年的分位 ≥90% 且同比回落时，自动降级 + 周期顶部风险提示（区分「高位回落」与「成长创新高」）
- **风险因子逐层筛查（11 层，逐项实查）**：①应收/存货质量（占比与增速 vs 营收，识别利润含水量）②商誉/净资产比 ③股权质押（口径日期标注）④股东户数变化（筹码集中度）⑤近 90 天大股东/高管减持 ⑥毛利率同期可比趋势 ⑦营收-现金流背离 ⑧交易流动性 ⑨业绩预告（预减/首亏/预亏=🔴，预增/扭亏=正向确认）⑩限售解禁（未来 3 个月最大单笔占比）⑪行业估值分位（PE 在同行业中的位置 vs 增长匹配度）。综合风险分级（低/中/高/极高），RISK 级因子自动阻止"加仓"决策降级为"持有"，并注入决策注释
- **结论速览**：深度分析报告顶部一句话概括「三态决策 · 评级 · 风险等级 · 业绩预告确认」，10 秒抓住重点
- **风险核验**：未来 3 个月限售解禁、分红连续性、经营现金流质量
- 四期财务趋势、近 2 年 K 线位置（52 周回撤 / MA250 / 60 日动量）、分红记录

### 2. 多轮漏斗选股（网页版）

从全市场约 5000 只 A 股逐轮收敛到终选 N 只，每轮展示数量与剔除原因：

```
轮次1 全市场 5000+
  → 轮次2 基础质量过滤（剔 ST/退市、亏损、PE>150、市值<30亿、仙股）
  → 轮次3 策略初筛（QARP ∪ 高股息 ∪ 深度回调，按分取前 60）
  → 轮次4 财务核验（逐股实查：盈利/增速/现金流/ROE/分红连续性/扣非质量）
  → 轮次5 位置核验（逐股实查 K 线：不在 52 周顶部、动量>-15%、不在创新低路径）
  → 轮次6 综合评分排序 + 行业分散约束 → 终选 N 只
```

内置三条可组合的初筛策略：

| 策略 | 逻辑 |
|---|---|
| **QARP 价值成长** | 质量合理价格：PE 3~30 + 大市值 + 扣非增长为正 |
| **高股息** | 股息率 ≥4%，按股息率/PE 综合排序 |
| **深度回调** | 年初至今跌幅 >15%，左侧布局候选池 |

### 3. 个股深度分析（网页版 · 持仓视角）

在个股扫描结果上点击「🧪 深度分析」，生成一份**六大章节的 Markdown 完整报告**（自动落盘到 `output/`）：

- **数据范围声明**：明确每项数据（行情/K线/财务/扣非/分红/解禁）的来源、覆盖区间与截至时间——所有结论仅在该范围内有效，[MISSING] 项透明标注
- **综合评分**：100 分制分维度得分卡
- **基本面 / 技术面**：四期财务趋势 + 扣非 + 周期分位 + 分红/解禁；52 周区间 / 均线 / 60日与120日动量
- **持仓三态决策**（与"建仓决策卡"的未持仓买入视角互补，规则透明可复算）：

| 决策 | 触发规则（任一/同时） | 输出 |
|---|---|---|
| 🔴 **弃仓** | ①亏损且净利同比恶化 ②评分<45 ③扣非≤-30%且60日≤-15%双杀 ④距顶回撤≥50%且创新低 | 清仓或减半 + 反弹离场参考价 + 无条件红线 |
| 🟢 **加仓** | 评级A/B + 60日企稳(≥-5%) + 非亏损 + 现金流非负或扣非增长 | 加仓两档价位 + 右侧确认线 + 止损/止盈区 |
| 🟡 **持有** | 其余中间态 | 转加仓触发（站稳MA20+动量转正）与转弃仓红线（52周低点×0.97）双向价位 |

### 5. 选股工作流（网页版 · 从初筛到决策的闭环）

- **策略初筛**：三条策略一键跑全市场，结果表支持**导出 CSV**
- **批量精评**：初筛 Top10（或自选清单全量）一键逐股扫描，按综合评分重排——把"快照初筛"升级为"实查精评"，这是选出最终名单的关键一步
- **自选清单**：扫描页 ★ 收藏（localStorage 本机保存，不上传），支持清单批量精评排序
- **多轮漏斗**：六轮收敛 + 行业分散约束，终选表每行可**一键直达深度分析**（11 层风险筛查）
- **多入口决策**：初筛表点击行 → 完整扫描；漏斗/批量/自选行内「深度」按钮 → 跳过中间步骤直达持仓三态决策

### 6. 评级与操作映射

| 评级 | 分数 | 建议 |
|---|---|---|
| A | ≥75 | 优质股，可按决策卡建仓 |
| B | ≥60 | 良好，小仓试探或等待右侧信号 |
| C | ≥45 | 中性，观察等待触发条件 |
| D | <45 | 回避，财报修复后重估 |

## 🚀 快速开始

无需安装任何第三方包，Python 3.8+ 即可：

```bash
# 克隆
git clone https://github.com/sylvia-ccc/a-stock-scanner.git
cd a-stock-scanner

# 网页版（默认 8080 端口）
python3 webapp/app.py 8080
# 浏览器打开 http://localhost:8080

# 或零门槛一键启动（macOS 双击 start_mac.command / Windows 双击 start_win.bat）

# 命令行版：扫描一只或多只股票，Markdown 报告输出到 output/
python3 scripts/stock_scanner.py 603019 601012 600941
```

## 🔌 数据源（全部免费公开接口）

| 源 | 用途 |
|---|---|
| 腾讯行情 `qt.gtimg.cn` | 实时价 / PE_TTM / 市值 / 换手 |
| 腾讯 K 线 `web.ifzq.gtimg.cn` | 2 年日 K（前复权） |
| 新浪行情 `quotes.sina.cn` | 日 K 备用源（三级降级） |
| 东方财富 `datacenter-web` | 业绩报表 / 分红 / 解禁 / F10 主要指标（含扣非） |
| 东方财富 `push2` | 全市场快照列表（限流时自动降级腾讯列表接口） |

数据源均为多级降级设计：东财 → 腾讯 → 新浪，单源限流不影响整体可用性。
