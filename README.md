# A股全景扫描器 (A-Stock Scanner)

> 纯 Python 标准库实现的 A 股全景扫描与多轮漏斗选股工具 —— **零第三方依赖**，一个文件跑通「搜索 → 扫描 → 评分 → 建仓决策」全流程。

## ✨ 功能

### 1. 个股全景扫描（网页版 + 命令行版）

输入任意 A 股代码（支持约 5400 只沪深标的），自动生成完整报告：

- **100 分制评分卡**：盈利能力 20 + 成长性 20 + 财务健康 15 + 估值 15 + 技术位置 15 + 股东回报 10 − 风险扣分
- **建仓决策卡**：明确的买卖动作与逐档触发价位（首批建仓价 / 加仓两档 / 止损价 / 减仓评估区），盘中取实时价、收盘后取收盘价
- **扣非核验**：归母净利 vs 扣非净利对比，识别「政府补贴/卖资产撑利润」的假增长
- **周期分位提示**：年度扣非在近 10 年的分位 ≥90% 且同比回落时，自动降级 + 周期顶部风险提示（区分「高位回落」与「成长创新高」）
- **风险核验**：未来 3 个月限售解禁、分红连续性、经营现金流质量
- 四期财务趋势、近 2 年 K 线位置（52 周回撤 / MA250 / 60 日动量）、分红记录

### 2. 多轮漏斗选股（网页版）

从全市场约 5000 只 A 股逐轮收敛到终选 N 只，每轮展示数量与剔除原因：

```
轮次1 全市场 5000+
  → 轮次2 基础质量过滤（剔 ST/退市、亏损、PE>150、市值<30亿、仙股）
  → 轮次3 策略初筛（QARP ∪ 高股息 ∪ 深度回调，按分取前 60）
  → 轮次4 财务核验（逐股实查：盈利/增速/现金流/ROE/分红连续性/扣非质量）
  → 轮次5 位置核验（逐股实查 K 线：不在 52 周顶部、动量>-15%、不在创新低路径）
  → 轮次6 综合评分排序 + 行业分散约束 → 终选 N 只
```

内置三条可组合的初筛策略：

| 策略 | 逻辑 |
|---|---|
| **QARP 价值成长** | 质量合理价格：PE 3~30 + 大市值 + 扣非增长为正 |
| **高股息** | 股息率 ≥4%，按股息率/PE 综合排序 |
| **深度回调** | 年初至今跌幅 >15%，左侧布局候选池 |

### 3. 评级与操作映射

| 评级 | 分数 | 建议 |
|---|---|---|
| A | ≥75 | 优质股，可按决策卡建仓 |
| B | ≥60 | 良好，小仓试探或等待右侧信号 |
| C | ≥45 | 中性，观察等待触发条件 |
| D | <45 | 回避，财报修复后重估 |

## 🚀 快速开始

无需安装任何第三方包，Python 3.8+ 即可：

```bash
# 克隆
git clone https://github.com/sylvia-ccc/a-stock-scanner.git
cd a-stock-scanner

# 网页版（默认 8080 端口）
python3 webapp/app.py 8080
# 浏览器打开 http://localhost:8080

# 命令行版：扫描一只或多只股票，Markdown 报告输出到 output/
python3 scripts/stock_scanner.py 603019 601012 600941
```

## 📐 项目结构

```
a-stock-scanner/
├── scripts/
│   └── stock_scanner.py   # 命令行扫描器（数据管道 + 评分引擎，可独立使用）
├── webapp/
│   └── app.py             # 网页版（http.server，含漏斗选股与建仓决策）
└── output/                # 报告输出目录（自动创建）
```

## 🔌 数据源（全部免费公开接口）

| 源 | 用途 |
|---|---|
| 腾讯行情 `qt.gtimg.cn` | 实时价 / PE_TTM / 市值 / 换手 |
| 腾讯 K 线 `web.ifzq.gtimg.cn` | 2 年日 K（前复权） |
| 新浪行情 `quotes.sina.cn` | 日 K 备用源（三级降级） |
| 东方财富 `datacenter-web` | 业绩报表 / 分红 / 解禁 / F10 主要指标（含扣非） |
| 东方财富 `push2` | 全市场快照列表（限流时自动降级腾讯列表接口） |

数据源均为多级降级设计：东财 → 腾讯 → 新浪，单源限流不影响整体可用性。
